# Credits and project origin

MUI Reborn is a continuation and Retail compatibility effort based on MayronUI.
The original design, architecture and substantial portions of the implementation
were created by Mayron and the MayronUI contributors. Their work remains the
foundation of this project and must be credited in redistributed builds.

The Compat22 restoration used for this merge includes compatibility work and
fixes from Robin/Monster (Alizmer), Monkey and other community contributors.

Upstream project reference:
https://github.com/cradzwill/MayronUI-Official

Bartender4, Shadowed Unit Frames Redux, Masque and Bagnon are separate projects
owned by their respective authors. Their source code is not bundled with MUI
Reborn.
